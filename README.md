# Miquel's theorem in Lean 4

A Lean 4 + Mathlib formalisation of **Miquel's theorem** for a triangle, proved by an explicit
polynomial (coordinate) certificate.

> Let `A B C` be a non-degenerate triangle in the plane `ℂ`, and let `F`, `E`, `D` lie on the lines
> `AB`, `CA`, `BC` (extended sides allowed), none of them at a vertex. Then the circles `(AEF)`,
> `(BFD)` and `(CDE)` pass through a common point `M`, the Miquel point.

Points are given by real parameters, `F = A + n(B − A)`, `E = A + t(C − A)`, `D = B + u(C − B)`
with `n, t, u ∉ {0, 1}`; non-collinearity is `Dp A B C ≠ 0`, and `Dp_eq_zero_iff_collinear` ties
this to Mathlib's `Collinear`. With these hypotheses each of the three triples is non-collinear, so
each circle exists and is unique. Distance is Mathlib's `dist` on `ℂ`.

The algebraic core is a certificate in a translation-invariant frame: with
`K = n t u (n − 1) |B − A|²`, the third circle polynomial `q3` satisfies
`K·x·q3 = P₁ q1 + P₂ q2` and `K·y·q3 = P₁' q1 + P₂' q2` with `P`, `P'` linear (`cert_x`, `cert_y`),
together with a tangency identity (`tang`) for the case `M = F` and a separation identity (`sep`).
Every identity is closed by `ring`.

**Status:** all statements proved, with no `sorry`. `gate.sh` checks 101 named declarations.

## Layers 14 and 15

`Miquel/L14.lean` restates the theorem using only Mathlib notions (`Collinear`, `line[ℝ, _, _]`, `Cospherical`) and instantiates it at a configuration with two points on extended sides; it adds 7 gated declarations. `Miquel/L15Classical.lean` reproduces verbatim, in namespace `Miquel.Classical`, 3 classical statements written independently from textbook statements by an AI model that did not see this code, and proves all 3 from this development: Miquel's theorem for points on the open sides and on the extended side lines, and the non-collinearity of the three point triples. The proofs carry `EuclideanSpace ℝ (Fin 2)` over to `ℂ` by a Mathlib isometry. It adds 10 gated declarations. None of the writer's statements was shown false.

## Verification

`./gate.sh` builds the library and generates its own `#print axioms` queries for 101 named
declarations, fully qualified (every declaration cited in `SPIKE_REPORT.md`, plus the supporting
lemmas, definitions, bridges and witnesses). The queries are generated by the gate itself, not read
from a file in the repository.

The gate fails if any of the following is true:
- a source file (`Miquel/*.lean`, `Miquel.lean`) contains `sorry`, `admit`, `native_decide`, `axiom`, `#eval`, `run_cmd`, `initialize`, `IO`, `set_option`, `macro`/`elab`/`syntax`/`notation`/`infix`/`prefix`/`postfix`, `import Lean` or `open Lean`;
- the build fails;
- a named declaration is missing, or has an extra report;
- a named declaration depends on anything other than `propext`, `Classical.choice` and `Quot.sound`.

Output: `PASS (101 declarations, standard axioms only)`. Some of these are definitions, which may
use a subset of the three axioms.

`tests/tamper.sh` plants six kinds of fake proof in scratch copies (in `Miquel/Main.lean`) and
checks that the gate rejects each one (a rejection must exit nonzero and print the expected `FAIL`
message). The real repository is never modified.

| Test | What it plants |
|---|---|
| sorry | a `sorry` |
| ax2line | an axiom split across two lines |
| evalfake | an `#eval` that prints a fake axiom report |
| macro | a custom macro that rewrites `#print axioms` |
| falsehyp | the hypothesis `n ≠ 0` dropped from `miquel` (with `n = 0`, `F = A` and the circle `(AEF)` is not determined, so the statement is false in general) |
| wrap | a genuine extra axiom with a long name, so the report wraps over several lines |

`tests/tamper.sh` needs a prior `lake build` (it reuses `.lake/build`); run the tests one at a time.
Both scripts use only POSIX shell tools and `awk` (no GNU `sed -i`, no GNU `mktemp` extensions,
no Python).

`code/check_miquel_formal.py` checks the exact formal configuration independently in floating
point (extended sides included) on 20 000 random cases: the worst relative residual of the Miquel
point on the three circles is about `2.3e-11`, while the negative control (`F` on circle 3) has
residual at least `2.7e-5`; it also prints the Lean negative-control distance (about `0.94`).
`SPIKE_REPORT.md` is the development log; it mentions an earlier numerical script, a scratch axiom
file and build logs that are not part of this repository.

## Scope

- The statement is in `ℂ` with explicit coordinates and `dist`; it is not phrased with Mathlib's
  `EuclideanGeometry.Sphere` / `Cospherical` API.
- Degenerate cases are excluded rather than handled: a collinear triangle, or `D`, `E`, `F` at a
  vertex.
- `M` is not proved distinct from `D`, `E`, `F`; it can coincide with them in tangent
  configurations, and the theorem allows this.
- Corollaries (spiral similarity, the Miquel point of a complete quadrilateral, the pentagon
  theorem) are not formalised.

## Prior art

A best-effort search (the Mathlib `v4.33.1` sources and `docs/100.yaml` / `docs/1000.yaml`, GitHub
code, repository and pull-request search, the Isabelle AFP, HOL Light, Rocq/Coq and Mizar) found no
complete formal proof of Miquel's theorem. Synthetic geometry libraries in the GeoCoq tradition and
Wu/Gröbner-basis provers use it as a standard benchmark; those are automated-prover benchmarks, not
library theorems with a stated degeneracy analysis. No claim of priority beyond this search is made.

## Build

```sh
curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh   # if Lean is not installed
lake exe cache get
lake build
./gate.sh
bash tests/tamper.sh
```

Requirements: a working `git` (Lake uses it to fetch the pinned Mathlib) and the pinned Lean
toolchain, Lean `v4.33.1` (`lean-toolchain`; `elan` installs it automatically), with Mathlib
`v4.33.1` (revision pinned in `lake-manifest.json`). `gate.sh` never fetches: run
`lake exe cache get` (or `lake build`) first so that the pinned Mathlib checkout is present in
`.lake/packages`.

## How to run the checks

From the repository root, after the build steps above:

```sh
lake build                 # build the library (pinned Lean and Mathlib)
./gate.sh                  # sorry/axiom/token gate; prints PASS (N declarations, standard axioms only)
bash tests/tamper.sh       # plants six fake proofs in scratch copies; each must be rejected
python3 code/check_miquel_formal.py   # independent floating-point check (not part of the proof)
```

`gate.sh` exits nonzero on any failure. `tests/tamper.sh` reuses `.lake/build`, so run `lake build`
first. The checker script is deterministic (fixed random seed) and needs only Python 3 and its standard library.
